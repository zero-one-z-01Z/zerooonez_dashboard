# واجهة مولد الموارد

مدخل الصفحة هو [builder.js](../builder.js). ينسق بين ثلاث وحدات صغيرة:

| الملف | مسؤوليته |
| --- | --- |
| [editor.js](editor.js) | إضافة وحذف وترقيم الحقول، قراءة التعريف وتعبئته، وتنزيل JSON. |
| [api.js](api.js) | POST للتعريف مع CSRF وتحويل فشل HTTP إلى Error مفهوم. |
| [preview.js](preview.js) | عرض محتوى الملفات وخطوات الإكمال والنتيجة كنصوص. |

التدفق: تحرير التعريف ← معاينة من الخادم ← مراجعة الملفات ← إرسال نفس التعريف والبصمة للإنشاء. أي تعديل يبطل المعاينة؛ revision يمنع ظهور رد سابق بعد تغيير البيانات، وbusy يمنع تزامن النقرات. الاستيراد والتصدير يتعاملان مع تعريف JSON؛ الخادم وحده يفحص المسارات والتعارضات ويكتب ملفات Laravel.

لإضافة نوع حقل، اتبع [دليل المولد](../../../../docs/dashboard/generator.md) لتحديث عقد الخادم مع الواجهة. [مرجع JavaScript](../../../../docs/dashboard/javascript-reference.md) يشرح كل دالة ومعالج؛ و`tests/JavaScript/builder-ui.test.js` يغطي عقود الواجهة. الأوامر الظاهرة بعد التوليد تعليمات للمطور ولا ينفذها المتصفح.
